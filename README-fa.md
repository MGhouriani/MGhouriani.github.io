# TradeDesk V8

نسخه بازطراحی‌شده داشبورد معاملاتی با نوار ناوبری ثابت در پایین صفحه، الهام‌گرفته از نوار اپلیکیشن‌های iOS، تم مشکی و نارنجی، و فرم ژورنال چندبخشی برای ثبت موقعیت، تایم‌فریم، ستاپ، ریسک، قیمت ورود/حد ضرر/حد سود، نتیجه، احساسات، پایبندی به پلن و درس معامله.

## انتشار با GitHub Pages
1. از نسخه فعلی خود خروجی JSON بگیرید و آن را خصوصی نگه دارید.
2. فایل `index.html` را در ریشه یک مخزن GitHub قرار دهید.
3. در Settings → Pages، گزینه Deploy from a branch را انتخاب کنید و شاخه `main` و مسیر `/(root)` را تنظیم کنید.
4. اطلاعات معاملاتی را داخل مخزن قرار ندهید؛ برنامه از ذخیره‌سازی محلی مرورگر استفاده می‌کند.

این نسخه هنوز برای همگام‌سازی بین دستگاه‌ها به پایگاه داده و ورود کاربر نیاز دارد.
